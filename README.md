# AI SOFUBI STUDIO

ソフビ原型制作を支援するWindows向けローカルアプリです。
公式サイト：https://antrec.ai

## 配布状況

正式署名付きリリースは準備中です。現在、正式公開版はありません。
公開後はこのリポジトリのReleasesからインストーラーと日本語ガイドを取得できます。
未署名の開発版は正式版と区別します。

## このリポジトリについて

配布専用です。ソースコード、APIキー、制作プロジェクト、モデル、バックアップは公開しません。オープンソース化を意味しません。
更新・アンインストール時にも制作データとバックアップを保持する設計です。

## 更新への移行

旧0.10.0以前からGitHub更新へ移行する場合、最初の1回は新しいセットアップで手動更新します。その後、正式な更新設定JSONをメンテナンス画面から取り込んでください。
秘密鍵を含むファイルは配布しません。
